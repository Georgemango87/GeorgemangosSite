⚙️ Settings

• Create folders with the 📁+ button in the toolbar. Set a name and color.
• Drag a gate button onto a folder button to move it in. Drag a gate from a folder to the toolbar to make it loose.
• Right-click a folder to rename, recolor, or delete it.
• Right-click a custom gate (toolbar or canvas) to edit it.
• Shift+drag to box-select, Shift+click to multi-select.
• Click an output port to enter pour mode (orange), click inputs to wire.
• Shift+click an input port to wire from the next selected source (round-robin).
• Click a wire to select (yellow) • double-click or right-click a wire to delete it.
• Ctrl+C / Ctrl+V to copy & paste selected gates.
• Undo/Redo: Ctrl+Z / Ctrl+Shift+Z.
• Debug mode: press D. Hover gates/wires to inspect; click a gate body or wire to pin; Esc to unpin.
• Collab: click 🌐 Share to sign in, host a room, or join one — you'll see everyone's live cursor.
