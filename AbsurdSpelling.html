How it works

This tool uses the Carnegie Mellon University Pronouncing Dictionary (CMUdict) to look up the pronunciation of each English word. CMUdict stores pronunciations in ARPAbet, which are converted to IPA phonemes. Each IPA phoneme is then replaced by the strangest valid English spelling pattern we could find.

For example, the /p/ sound can be spelled gh (as in hiccough), /t/ can be phth (as in phthisis), and /oʊ/ can be eau (as in plateau) or ough (as in though).

Words missing from the dictionary fall back to a simple letter-to-sound rule and are marked with ‹…› so you can see where the fallback was used.
