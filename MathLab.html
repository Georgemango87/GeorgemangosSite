MathLab — build mathematical systems

    
Write a program. Each line defines something reusable. Everything is connected:
       change one definition and the whole system re-evaluates automatically.


    
Definitions

    

      a = 5 · f(x) = a*x^2 + 3 ·
      v = [1,2,3] · M = [[1,2],[3,4]] · A = {1,2,3}
    


    
Conditional rules

    
f(x) = x > 0 ? x^2 : -x   (ternary)


    
Iteration / stateful systems

    

      x(0) = 0.5

      x(n+1) = r*x(n)*(1-x(n))

      Then call x(10), x(100)… and step through time with the
      simulation controls at the bottom.
    


    
Recursion

    
fib(0) = 0
fib(1) = 1
fib(n) = fib(n-1) + fib(n-2)


    
Composition

    
h(x) = g(f(x))   or   h = compose(g, f)


    
Operators

    
+ - * / ^ %, comparisons < > <= >= = !=,
       logic and/or, ternary ? :,
       sets ∪ ∩ \. Implicit multiplication works: 2x, (x+1)(x-1).


    
Built-in functions

    
sin cos tan asin acos atan sinh cosh tanh sqrt cbrt abs exp ln log log2
       floor ceil round sign min max mod gcd lcm factorial hypot atan2 compose

    
Linear algebra: dot cross norm transpose det inv identity zeros ones

       Sets: union intersect difference

       Calculus: derivative(f), integral(f,a,b), limit(f,a),
       roots(f,a,b), tangent(f,a)

       Series: sum(expr, k, from, to), product(expr, k, from, to)

       Random: random(), random(a,b)


    
Views

    
System — the whole project as a dependency graph.

       Build — the selected object's AST as editable blocks; edits write back to code.

       Graph / Number line — the visualisations.


    
Parameters

    
Click the ⚙ icon on a numeric object to turn it into a slider parameter.
