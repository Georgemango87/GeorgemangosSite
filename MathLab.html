  2. Drag on canvas to orbit · scroll to zoom · space to pause.
  3. Open Build to edit formulas and sliders.

The four slots

Every mode has the same four expressions: x, y, z, c. The mode decides which variables are in scope and what the slots mean:

Modex, y, zcVariables
curve point on the curve color 0→1 u t i n
surface vertex of the grid color 0→1 u v t i n
attractor next point (rules) color 0→1 x y z i n r

Custom Parameters

Add names in the Parameters box. Each becomes a slider and a variable you can use in expressions.

Recipes

Twisting ring (curve):

x = cos(u*tau + t*0.2)
y = sin(u*tau + t*0.2)
z = sin(u*tau*3 + t) * 0.3

Rippling plane (surface):

x = 2*u - 1
y = 0.3*sin(12*u + 12*v + t*3)
z = 2*v - 1
c = 0.5 + y

Lorenz (attractor, add param dt 0.001–0.02):

x = x + dt*(10*(y - x))
y = y + dt*(x*(28 - z) - y)
z = z + dt*(x*y - 2.667*z)
c = 0.5 + 0.5*sin(i*0.002 + r*0.3)
